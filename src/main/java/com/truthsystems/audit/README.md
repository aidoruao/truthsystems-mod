If mod can self-repair AND pass all tests → unfrozen

### PATH B: External Patch (GRACE Principle)
1. GitHub Issue auto-created with full forensic report
2. External fixer writes patch
3. Patch must:
   - Be SHA-256 hashed
   - Pass all 4 tests in simulation
   - Be committed with error ID in message

### PATH C: Covenant-Ordered Deletion (CHALCEDON Principle)
1. Full rollback using Merkle hashes
2. Mod moved to `mods/quarantine/`
3. Entry added to `blacklist_manifest.json`
4. World restored to pre-violation state

## 🎯 USAGE

### Log an Error
```java
String errorId = ErrorLogger.logError(
    ErrorLogger.ErrorType.BIJECTIVE_VIOLATION,
    "pollution.jar",
    "swap(swap(x,y)) != identity",
    preStateHash,
    postStateHash
);
```

### Quarantine a Mod
```java
BlacklistManager.quarantineMod(
    "pollution.jar",
    "DEADBEEF1234...",
    List.of("BIJECTIVE_VIOLATION", "MERKLE_MISMATCH"),
    "A1B2C3D4E5F6..."
);
```

### Check if Blacklisted
```java
if (BlacklistManager.isBlacklisted(modHash)) {
    // Reject mod load
}
```
